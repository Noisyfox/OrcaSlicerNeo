# Windows cmd Build Pipeline

**Updated:** 2026-10-11
**Status:** Current engineering reference

## Entry points and ownership

Use `scripts\build-windows.bat` on Windows, with no Git Bash dependency.
macOS/Linux/CI use `scripts/build.sh`. [README](../README.md#building) and each
driver's `help` own the command catalogue. Start Windows cold builds from a
Visual Studio developer prompt or with a supported native compiler on PATH.
A plain shell without a compiler cannot bootstrap Boost.

| Owner | Responsibility |
| --- | --- |
| `packages/slicer-wasm/fetch-deps.bat` | Native curl/tar, dependency headers and Boost bootstrap |
| `packages/slicer-wasm/build-boost-wasm64.bat` | b2 archives with explicit em++/emar/emranlib paths |
| `packages/slicer-wasm/build.bat` | External patches, shims, version headers, CMake and Ninja for one variant |
| `scripts/build-wasm-dual.bat` | Both variants, then `node scripts/stage.mjs` |
| `scripts/build-windows.bat` | Environment activation, dispatch, incremental build and smoke |

`WASM_THREADING` and `WASM_ARTIFACT_VARIANT` select `.work/<variant>` and
`out/<variant>`. Quick builds reuse the configured tree, rebuild and copy the
three JS/WASM/data artifacts; they do not change CMake feature gates. Use
`build` when those inputs change. Follow [DWARF builds](2026-08-20-wasm-dwarf-debug-build.md)
for debug configuration and restoring release artifacts.

## Batch-language constraints

1. **Explicit executable paths.** With `NoDefaultCurrentDirectoryInExePath=1`,
   cmd skips current-directory lookup for bare executables and batch files.
   Use `.\b2.exe`, `call .\bootstrap.bat` and other explicit paths. Check
   executable availability with `where` or `if exist`; do not assume that a
   successful MSYS lookup establishes cmd behavior.
2. **Escaped parentheses.** Inside `if (...)` / `for (...)`, escape parentheses
   in echo text as `^( ... ^)`. An unescaped closing parenthesis can terminate
   the guarded block and execute following commands unconditionally.
3. **CRLF.** Batch files must use CRLF, enforced by `.gitattributes`. Verify no
   bare LF after editing; malformed multiline blocks can look like logic bugs.
4. **Stale b2 configuration.** Remove stale autogenerated `project-config.jam`
   before b2: backslashes in an old quoted Python path are Jam escapes and can
   turn a Windows path into a bogus command. The fetch and Boost builders own
   this cleanup.
5. **Environment activation.** Call `emsdk_env.bat` in the driver process so
   activation persists for its commands. Interactive parent shells require
   their own activation. The driver owns installation search order; do not
   assume an old machine's warmed SDK location is portable.
6. **Consistent wasm64 flags.** Use `-m64` at compilation and link, including
   dependency b2 C/C++ flags. Do not mix deprecated `-sMEMORY64` spelling or
   mismatched targets across archives.
7. **Stable path spelling.** Normalize CMake paths with `%VAR:\=/%` so the
   cache uses forward slashes and reconfiguration does not churn on spelling.
8. **Explicit Boost toolset.** Boost 1.84 autodetection can classify newer
   Visual Studio as unsupported `vcunk`. Probe `cl`, `g++`, then `clang` and
   pass the matching bootstrap toolset. Clear
   `NoDefaultCurrentDirectoryInExePath` only around the upstream bootstrap,
   restore it afterward, and keep gcc/clang retries explicit. Report missing
   compilers honestly rather than depending on an existing dependency tree.
9. **Nested batch calls.** In `call :label` subroutines prefix `.cmd`/`.bat`
   invocation with `call`, including `call pnpm --filter @orca/desktop dev`.
   Otherwise cmd can hand over the batch context and lose the return label.
10. **No edits during execution.** cmd reads batch text lazily by byte offset.
    Never rewrite a running `.bat` or normalize its line endings, including
    while a background build is using it. Misaligned offsets can execute
    unrelated subroutines or produce garbage commands such as `errorlevel`
    and `f`. Rule out a mid-run edit before diagnosing those as source defects.
